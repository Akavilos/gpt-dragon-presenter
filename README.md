# Q 版白毛龙娘讲解员

拿着指挥棒的白毛、紫眸 Q 版龙娘，适合教程、软件演示和讲解视频。包含六张 1254×1254 透明 PNG，以及可直接打开的动画预览。

![讲解员](assets/neutral.png)

## 怎么用

下载整个仓库，解压后打开 `index.html`。可选择常态、说话、眨眼、星星眼、俏皮和认真表情，调整角色大小、动作幅度、背景与左右朝向。点击“移到左边 / 右边”，角色会移动并转向讲解区域。浏览器预览无需安装依赖。

导入本地音频并播放，嘴部随声音强弱开合，音频仅在本机处理。双口型不等于逐字唇形同步。录制浏览器画面可以用于视频；`assets` 中的 PNG 可以直接导入剪辑软件，使用缩放、位置、旋转和镜像关键帧。

手部保持握指挥棒的姿势，没有独立手臂骨骼。动作采用 Galgame 常见的画像弹动、倾身、点头和表情切换。全身统一使用常态画稿，表情只覆盖面部区域，避免不同生成帧的裙装、头发和轮廓跳动。

## 文件

- `assets/`：六张高清透明表情图。
- `index.html`、`presenter.js`：本地互动预览和可复用动画类。
- `manifest.json`：尺寸、面部区域及动作说明。
- `preview.mp4`：动作演示；`transparent.webm`：透明背景循环，生成后提供。
- `LICENSE`、`ASSET_RIGHTS.md`、`REFERENCE_RIGHTS.md`：代码与素材的使用范围和参考来源。
